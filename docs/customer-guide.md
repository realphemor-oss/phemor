# 非莫 · 离线学习使用说明（给客户）

**一次设置，以后不用等加载，没网也能学。**

## 第一步：用手机浏览器打开，添加到主屏幕

> 不要在微信里直接打开！微信里点右上角「···」→「在默认浏览器打开」（iPhone 选「在 Safari 中打开」）。

打开 `phemor.com/words/`：

- **iPhone（Safari）**：点底部「分享」按钮 → 「添加到主屏幕」 → 「添加」
- **安卓（Chrome / 系统浏览器）**：点右上角「⋮」→ 「添加到主屏幕」或「安装应用」（华为、小米选「添加到桌面」）

以后从桌面的「非莫」图标进入。第一次打开后停留一会儿（连着 Wi-Fi 最好），网页会自动把所有单词的文字存进手机。

## 第二步：去夸克网盘下载你的单词包

打开「非莫」→ 底部「我的」→「单词包」，点「打开夸克网盘」（提取码可以一键复制）。按自己的阶段选：

| 你是 | 下载 |
|---|---|
| 初中 | 初中包 |
| 高中 | 初中包 + 高中包 |
| 准备四六级 / 大学 | 初中包 + 高中包 + 大学包 |
| 准备雅思 | 以上全部 + 雅思进阶包 |
| 出国旅游 | 旅游包 |

后一个包只含前一个包没有的词，所以不会重复。不下前面的包也能学，只是那些基础词的插画会显示成文字图案。

想学几个就下几个，**建议连 Wi-Fi**，每个包 45–200 MB。

## 第三步：把包添加到「非莫」

1. 下载完成后，把文件保存到手机：
   - **iPhone**：夸克里点文件 → 分享 → 「存储到文件」
   - **安卓**：直接保存在手机的下载文件夹里
2. 回到「非莫」的「单词包」页，点「选择单词包文件」，选刚才下载的文件。
3. 看到「已添加」就成功了。装完可以开飞行模式试试，图片和发音照样都有。

> 文件名结尾是 `.phemor`，**不要改名，也不要手动解压**。

## 高中包、大学包等需要激活码

初中包免费，直接添加就能用。其余的包需要老师发给你的**激活码**：

1. 在「非莫」→ 单词包 →「授权」里点「复制设备码」，把它发给老师（iPhone 请在**主屏幕上的 App** 里操作，不要在 Safari 里）。
2. 老师回复一串以 `PHEMOR1.` 开头的激活码，整段复制，粘贴到「授权」的输入框，点「激活」。
3. 看到「已激活」后，再按第三步添加你下载的包文件。

激活码只需要激活一次，之后离线也能用。换手机或清除网站数据后，需要重新联系老师。

## 以后有新单词

老师会发给你一个新的单词包，按第三步添加即可。**学习进度不会丢。**

## 遇到问题

- 没装单词包也能学，只是没有插画（显示文字图案），发音用手机自带语音。
- 换手机或清理浏览器数据前：「我的 → 数据 → 导出备份」，新手机上「导入备份」。
- 提示空间不足：只装自己阶段的包，或在「单词包」页移除不用的包。
- 选不到刚下载的文件：确认它已经保存在「文件」（iPhone）或下载文件夹（安卓）里，而不是只在夸克 App 里。
